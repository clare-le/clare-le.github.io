# 電車Go

六家 ⇄ 竹中的原創列車駕駛遊戲雛形，以 EMU500 四節編組為車輛外觀原型。

- 單程 1.2 km 是遊戲縮尺，路線、站場、高架、建物與操縱參數均經簡化，並非實際鐵路重建。
- 銀色車體、藍色腰帶、橘色細線、每側三組車門與四節可見車廂；車內與車外視角可切換。
- 動力 P1–P5、惰行 N、煞車 B1–B7、緊急煞車 EB。
- 在目標前後 8 m 內施加煞車並完全停穩即可停站。停車誤差與超速會扣分。
- 竹中停站 4 秒後可換端折返；換端將駕駛位置移至同一組列車另一端。
- 回到六家後顯示兩程平均評分。越過停車位置 35 m，或在超過 8 m 後停住，會結束挑戰。

## 操作

| 操作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 增加動力／減少煞車 | ↑ | 動力 + |
| 增加煞車／減少動力 | ↓ | 煞車 − |
| 惰行 | N | N |
| 緊急煞車 | Space | 緊急煞車 |
| 車內／車外視角 | C | 頁首視角按鈕 |
| 暫停／繼續 | P | 暫停／繼續 |
| 全螢幕 | F | 頁首全螢幕按鈕 |
| 鳴笛 | H（先開啟音效） | — |

全部執行於瀏覽器，不需要帳號或後端。Three.js 0.185.1 隨附於 vendor，MIT 授權見 vendor/THREE-LICENSE.txt。圖形為程式生成，沒有使用原遊戲的圖像或音效素材。

## 開發檢查

從網站根目錄啟動 `python3 -m http.server 8766 --bind 127.0.0.1`，開啟 `/train-go/`。

- `window.render_game_to_text()`：可觀察的遊戲狀態 JSON。
- `window.advanceTime(ms)`：切換至人工步進，供瀏覽器測試使用；重新載入可恢復即時模式。
- 瀏覽器測試與截圖留在網站專案之外的 `project/tool/train-go-tests/`。
