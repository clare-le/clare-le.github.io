# 電車Go

六家 ⇄ 竹中的原創列車駕駛遊戲雛形，以 EMU500 四節編組為車輛外觀原型。

- 單程 1.2 km 是遊戲縮尺。路線依使用者提供的六家—竹中地圖截圖調整相對曲度與道路／河流順序，站場、地景與操縱參數均經簡化，並非實測鐵路重建。
- 銀色車體、藍色腰帶、橘色細線、每側三組車門與四節可見車廂；車內與車外視角可切換。
- 動力 P1–P5、惰行 N、煞車 B1–B7、緊急煞車 EB。
- 在目標前後 8 m 內施加煞車並完全停穩即可停站。停車誤差與超速會扣分。
- 竹中停站 4 秒後可換端折返；換端將駕駛位置移至同一組列車另一端。
- 回到六家後顯示兩程平均評分。越過停車位置 35 m，或在超過 8 m 後停住，會結束挑戰。

全部執行於瀏覽器，不需要帳號或後端。Three.js 0.185.1 隨附於 vendor，MIT 授權見 vendor/THREE-LICENSE.txt。圖形為程式生成，沒有使用原遊戲的圖像或音效素材。

## 開發檢查

從網站根目錄啟動 `python3 -m http.server 8766 --bind 127.0.0.1`，開啟 `/train-go/`。

- `window.render_game_to_text()`：可觀察的遊戲狀態 JSON。
- `window.advanceTime(ms)`：切換至人工步進，供瀏覽器測試使用；重新載入可恢復即時模式。
- 瀏覽器測試與截圖留在網站專案之外的 `project/tool/train-go-tests/`。

## 路線與地景（第二版）

依 2026-09-08 使用者附圖手動配置：六家 → 興隆路五段 → 頭前溪鐵橋 → 台 68 線 → 下員山／員山路 → 竹中。另有六家端的文興路二段與高鐵五路。

- 取消反覆左右蛇行，改為出站平順曲線、跨河後長直段，以及竹中站前較緩的收彎。截圖遮住的站前細節採簡化配置。
- `route.js` 是共用的路線資料：弧長採樣、道路折線、河道、建物保留區與地景里程。
- 車廂、鏡頭、鋼軌、護欄與分段站台都使用同一組弧長／切線／法向量，保持四節列車間距及換端位置連續。
- 頭前溪包含開闊水面、沙洲與河濱支流。主要河道與道路走廊不生成隨機建物。
- 鐵路整體抬高，台 68 以較低高架穿越；交會處跳過鐵路橋墩，保留道路空間。
- 畫面顯示目前沿途地景，去回程共用同一個世界。

所用參考只有使用者提供的地圖截圖；沒有把截圖上傳、嵌入或當成遊戲貼圖。圖上的位置與比例不應解讀為精確地理資料。

## 竹中站前近圖修正（第三版）

依第二張近圖，終端改為南下長直線後向西轉彎，再沿東西方向進站。新增直線段前的公道路；竹中路配置於月台南側，並標為平行道路，避免誤列成鐵路途中跨越點。員山路名稱沿用前一張概覽，斜交方向參照近圖調整。

終點切線為西向（−90°）；仍維持 1.2 km 遊戲縮尺、四節 EMU500 與原停站／折返規則。
